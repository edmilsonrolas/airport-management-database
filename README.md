# airport-management-database
Relational database design and Oracle PL/SQL implementation for airport operations, including flight scheduling, resource allocation, aircraft maintenance, reservations and check-in.

## Features

- Flight scheduling and rescheduling
- Aircraft management and maintenance
- Runway and gate allocation
- Passenger reservations and check-in
- Database integrity and operational constraints

## Technologies

- Oracle Database 21c XE
- SQL
- PL/SQL
- Mermaid (ER diagram)
